# CGP animé

Un petit film d'une minute en papier découpé qui présente le métier de conseiller en gestion de patrimoine : la rencontre, l'écoute des projets, le bilan, les outils, le réseau d'experts et le suivi dans le temps.

Tout tient dans `index.html` : les dessins, l'animation et la musique sont générés directement par le navigateur.
